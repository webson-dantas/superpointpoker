# 🃏 SuperPoint Poker

Planning Poker for agile teams — with love, by Webson <3

A lightweight, real-time planning poker app built with Streamlit. No database required — runs entirely in-memory.

## Features

- Create and join planning poker sessions via session ID or shareable link
- Roles: Hoster, Dev, QA, Observer
- Fibonacci-based story point estimation
- Auto-reveal when all voters have voted
- Configurable: separate Dev/QA averages, hoster voting, anyone-can-reveal, block vote changes after reveal
- Shame mode (RGB animation) for slow voters
- Voting history per session
- Optional Cloudflare tunnel for instant public sharing

## Requirements

- Python 3.9+
- (Optional) [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) for public URL tunneling

## Setup

1. **Clone the repository**

   ```bash
   git clone <your-repo-url>
   cd superpointpoker
   ```

2. **Install dependencies**

   ```bash
   pip install -r requirements.txt
   ```

3. **(Optional) Generate SSL certificates** for HTTPS mode:

   ```bash
   openssl req -x509 -newkey rsa:2048 -keyout key.pem -out cert.pem -days 365 -nodes
   ```

4. **(Optional) Install cloudflared** for public tunnel access:

   ```bash
   # Windows
   winget install Cloudflare.cloudflared

   # Linux/macOS
   # See https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
   ```

## Running

### Quick start (with tunnel + HTTPS)

```bash
python run.py
```

This will:
- Start Streamlit on port 8000 with HTTPS (requires `cert.pem` and `key.pem`)
- Automatically create a Cloudflare tunnel and print a shareable public URL

### HTTP mode (no SSL certs needed)

```bash
python run.py --http
```

### Run Streamlit directly (no tunnel)

```bash
streamlit run app.py
```

## Usage

1. Open the app in your browser (local URL or the Cloudflare tunnel URL)
2. Enter your display name
3. **Create a session** or **Join an existing one** by selecting a role (Dev, QA, Observer)
4. Share the session link with your team (click "🔗 Link to this session" inside the session)
5. The Hoster manages rounds: sets ticket labels, reveals votes, clears for next round
6. Results show averages and closest Fibonacci number

### Session Configuration (Hoster only)

- **Separate Dev & QA averages** — Show individual averages per role
- **Hoster votes?** — Allow the hoster to participate in voting
- **Anyone can reveal votes** — Let any participant reveal, not just the hoster
- **Block vote change after reveal** — Lock votes once revealed

## Architecture

- **Framework**: Streamlit with `streamlit-autorefresh` for polling (2-second interval)
- **State**: In-memory Python dictionary (shared across all Streamlit sessions via `st.cache_resource`)
- **Concurrency**: Thread-safe with separate locks for state mutations and heartbeats
- **Cleanup**: Stale participants removed after 60s inactivity; stale sessions removed when host is inactive 60s

## Configuration

Server settings are in `.streamlit/config.toml` (auto-generated by `run.py`):

```toml
[server]
port = 8000
address = "::"
headless = true
```

## Notes

- All session data is in-memory — restarting the server clears all sessions
- Designed for small-to-medium teams (optimized for ~10-15 concurrent users per instance)
- No authentication — anyone with the link can join
